# Linux Audit
Скрипт находится в процессе разработки и в дальнейшем будет произведен рефакторинг и будут добавлены новые проверки. Этот проект является Курсовым проектом, и не претендует на идеальный аудит инструмент. 
Основная работа заключается в автоматизированном аудите безопасности Linux-системы с помощью скрипта. Программа последовательно проверяет аппаратные возможности процессора, права доступа к критическим файлам, настройки политик безопасности, сетевые настройки, состояние защитных механизмов, ищет критические уязвимости и формирует структурированный отчёт с рекомендациями по устранению уязвимостей

## Возможности
- Анализ политик ядра
- Поиск нежелательных учетных записей ( пользователей без пароля, лишние пользователи в sudo и так далее )
- Проверка прав доступа к критически важным файлам
- Возможность делать DUMP критически важных файлов системы для дальнейшей проверки их целостности 
- Проверка установленного соединения
- Проверка актуальности системы и обновлений 
- Проверка DNS
- Проверка установленных средств защиты
- Проверка прослушки портов 
- Проверка способа хешировния пароля администратора 
- При аргументе “l” или “L” будет произведено сохранение результата отчета в log – файла с описанием времени, когда был произведен аудит 


## Требования
- Debian-подобные дистрибутивы (Ubuntu, Kali Linux и др.)
- Bash 4+
- (скрипт уже может определять, в каком дистрибутиве он запущен. Однако, могут быть проблемы на запуске в Fedora – подобных системах)

## Установка зависимостей
Скрипт автоматически проверит наличие или отсутствие средств защиты, а так же подскажет как их при желании установить 

## Важно
Скрипт требует прав sudo, так как проверяет критически важные файлы, однако в дальнейшем я планирую реализовать обычную проверку ( без sudo), так и расширенную 


## Использование 
```bash
git clone 
chmod +x auditor.sh
sudo ./auditor.sh
```
